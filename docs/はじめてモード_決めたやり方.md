## 測り方（測定条件）を決める・登録する（2026-11-25 設計の段2）
- ホームの5つ目のタイル「測り方を決める・登録する」（流れ `cond`）: 何を測るか（分割だけ／再現性だけ／両方）と回転か傾斜 → 分割の条件（円盤の目盛りと「360 ÷ 刻み ＝ N か所」）→ 再現性の条件（止まる所に印）→ 「この型式で登録する」1回 → できました。
- 「測る」の流れにも、機械に入れる前に「測り方を確かめる」（`cond_check`）。登録があれば「自動で入りました」、無ければ赤く出して、その場で決めて登録→終わると、ここにもどる。
- 値は通常の画面の欄とつなぐだけ（`MainWindow.easy_cond_get/set/mode/state/register`）。登録は条件編集と同じ中身（`gui.condition_record`・`condition_targets`。条件編集の窓もそれを使う）。回転と傾斜・分割と再現性は別ファイルのまま。
- **会社の一覧と同じ値のときは、自分の分割登録を作らない**（作ると測定順が標準にもどり、主点評価が自動で入らなくなるため）。値を変えて登録するときは「これからは、あなたの登録を先に使います。測る順番は標準にもどります。」と出す。
- 未実装: かんたん作成（機械に入れる所）の「測定条件が見つかりません」から直接「測り方を決める」へ行く道（今は、その前の「測り方を確かめる」で決められる）。

## 「機械に入れる」の順番の訂正（2026-11-25 利用者・最終）

**誤り（2回）**: ①「つなぐ → 伝票番号」の順。②「製品に合う号機をアプリが自動で決める（◯号機 自動で決めました）」。
号機（制御装置）は**アプリが決めない**。作業者が、使える制御装置のリストから選ぶ（目の前の制御装置を選ぶ／リストを見て探しに行く）。

**流れは1つだけ**:
1. 受注伝票番号 → パラメータとモーター
2. そのモーターを動かせる制御装置のリスト（マスタから、容量・400V品は200V機で×2・末尾 -D は D駆動○で絞る）を出す
3. 作業者がリストから選ぶ（すでにつながっている機械の号機が分かれば、リストの先頭に★で出すだけ。選ぶのは人）
4. その号機につないで「つなぐ」。選んだ号機と合うか機械を読んで確かめる（CNC ID か 2165）。違えば赤い帯、未登録は BASIC を取って登録。**軸は自動で割り当てる**（2軸は2つ。［変える］は同じ容量の軸だけ）
5. 書く → 入れ直し → 測る → 保存

「先につなぐ」の別の道は作らない。
