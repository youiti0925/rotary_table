## 手順（章）
つなぐ → 製品を決める → 機械に入れる → 測る準備 → 測る → 結果と保存。
画面は、状態から要る所だけ出す: 機械が見えていれば「電源」を出さない。非常停止が解除済みなら出さない。つまみがもう合っていれば出さない。
電源の入れ直しは、機械に PW0000 が出ている／かんたん作成の中で入れ直しが要ったときだけ。原点復帰は、電源を入れたあと（電源の手順を出した・入れ直した）だけ。
表示器を0にする手順は設定 `fanuc_counter_reset`（既定 入）のときだけ。

## 非常停止の順番（2026-11-24 利用者の決定「パラメータは非常停止中だけ書ける」。別スレッドから連絡）
`focas_ops.estop_mode(True)`（設定 `param_write_estop`）に合わせる（`easy_ctx` の `param_estop`）:
- `estop_only`（既定）: つまみを MDI に → **非常停止を押す（estop_press）** → 機械に入れる（パラメータは押したまま書く。測定プログラムの前に、中のかんたん作成が「非常停止がかかっています。もどす」と絵で案内）→ 書き終えたら **非常停止をもどす（estop_release）**（まだ押してあるときだけ）→ 原点復帰 …
- `released_only`: 先にもどす（estop）→ 書く（前の順）。 `either`: 押す・もどす手順を出さない。
- 短い言葉は向きを間違えない: 「非常停止にして書きます／押してください」→「非常停止を押す」（押す絵）、「非常停止です」→「非常停止がかかっています。もどす」（もどす絵）。試験 `test_easy_mode`。
- 未確認: 非常停止中に機械が許可外のアラームを出して書けないことがないか（23号機で確かめる）。

## 機械から読んで自動で進めるもの（読めたものだけ。読めないときは人が押す小さなボタンを出す）
非常停止（emergency=0）・操作モード（aut: MDI=0／メモリ=1／原点復帰=9）・運転中（run=3）・つながっているか。
- **実機で確かめたのは「状態の値が読めること（MDI・リセット・アラーム）」まで。メモリ=1・原点復帰=9・運転中=3 の数値の読みは仕様の知識で、実機は未確認。**
  合わなければ、25秒たつと「機械から読めません。やったら、ここを押します」が出る（止まらない）。
- 選んだプログラム番号・原点復帰が済んだか・つまみの早送り倍率は読んでいない（人が「やりました」を押す）。

## 取込の順番
「緑の起動ボタンを押す」の手順に入ると、PC の取込を先に始める（`easy_start_capture`）。起動があと。
測り終わると自動で結果へ進む。外れがあれば「もう一度測る」が出る。保存は測定の画面の「セーブ」と同じ関数（上書きの確認は今までどおり）。
「別々に2本」は、保存のあと「次の測定へ」で、測り方を切り替えてプログラムの呼び出しからやり直す。

## 機械に入れる手順（第2版 2026-11-24 コーディネーター指示「画面の中に埋め込んでボタンを減らす」）
かんたん作成（ParamWizardDialog。受注伝票番号→軸の自動決定→控え→書く→プログラムを送る）を、**この画面の中に入れる**（別の窓を開かない。`EasyModeDialog._open_wizard_inside`）。
入れている間は、外側の「次へ」と件数を隠し、見えるのは「もどる」と小さな「もう機械に入っている（飛ばす）」だけ。かんたん作成の「全部表示」への切り替えと「閉じる」も隠す。
進むのは、中の「測定へ進む ▶」を押したとき（`finished` → 型式と測り方を測定の画面に入れて、自動で次の手順へ）。
開いている間は、機械を読む係を止める（同じ機械に2本つながない）。「もどる」「飛ばす」で片づけるときは、書いている最中なら今までと同じ確認が出る。
戻ってきたら、機械に入れ終えたか（`handoff`）と、電源の入れ直しが要ったか（`power_cycled`）を受け取る（`MainWindow.easy_wizard_result`）。
中の説明文・ボタンの文字は、かんたん作成のまま（はじめてモードの絵の案内にはまだ置き換えていない）。

## 入り口（ホーム）と、測る以外の流れ（2026-11-24 利用者「他も全部イラストメインで。プログラムも測定も全部」）
はじめてモードを開くと、まず絵の大きなタイル4つ: **測る／プログラムを機械に入れる／結果を見る・印刷／アラームを調べる**（`easy_flow.FLOWS`）。
- 各手順は `fl`（流れ名→何章目か）でどの流れに入るかを決める。上の章の帯は流れごとに変わる。「もどる」で入り口にもどれる。
- 測る: 今までどおり（6章）。
- プログラム: つなぐ（電源・非常停止・MDI）→ 機械に入れる（かんたん作成を中に入れる。書き終えたら非常停止をもどす・電源の入れ直し）→ おわり。
- 結果: 保存した結果をえらぶ（通常の「過去データ」と同じ画面）→ 見る（規格から外れた所の数は画面の赤い字を数えるだけ）→ 印刷／PDF（通常の関数を呼ぶ）。
- アラーム: 番号を入れる（機械に出ているアラームがあれば最初から入る）→ 意味・原因・やること（`fanuc_alarms` の検索と同じ中身）。
新しい決め方は作らず、今ある機能を呼ぶだけ（`MainWindow.easy_open_past / easy_print / easy_pdf / easy_alarm_info`）。通常の画面はそのまま。
実機は未確認。
