# 機番末尾のつけ方（社内の表「分割精度測定 機番末尾のつけ方」。2020/10/20 作成・2020/11/2 改定）

写真: `docs/機番末尾のつけ方_社内表_写真.jpeg`（2026-11-25 利用者が提供。表は横向きに撮影されている）。
**フルクロ（クローズ）は末尾 C、セミクロは文字なし**で区別する（この表で決まっている。仮の付け方は使わない）。

## 付け方（左から順に付ける）
`機番` ＋ ①モーターの種類 ＋ ②クランプ ＋ ③測る種類（複数あるときは表の列の順に並べる） ＋ ④精度NGの `-X番号`

① **モーターの種類**（表の行）: 駆動装置＝`K`／正規モータ＝（なし）／仮モータ＝`I`
② **クランプ**: アンクランプ＝（なし）／クランプ＝`G`
③ **測る種類**（表の列。左から右の順）:

| 測る種類 | 記号 | 例（駆動装置・アンクランプ） |
|---|---|---|
| セミクロ | （なし） | K |
| 傾斜単品 | T | KT |
| 回転単品 | R | KR |
| 多軸 | M（1軸目）・2・3・4 | KM, K2, K3, K4 |
| 対向（固定） | F | KF |
| 対向（移動） | S | KS |
| 修理受入 | U | KU |
| 修理後 | E | KE |
| クローズ（フルクロ） | C | KC |
| 傾斜完組（慣らし前） | TY | KTY |
| 回転完組（慣らし前） | RY | KRY |
| 傾斜完組・慣らし後 | DTY | KDTY |
| 回転完組・慣らし後 | DRY | KDRY |

行ごとの頭の文字: 駆動装置 K／駆動装置・クランプ KG／正規 （なし）／正規・クランプ G／仮モータ I／仮モータ・クランプ IG。
（例: 仮モータ・クランプの回転単品クローズ＝IGRC、正規モータの傾斜完組・慣らし後＝DTY、駆動装置クランプの多軸3軸目＝KG3）

## ルール（表の下の文）
- **精度NG**のときは、機番の一番後ろに `-X1` を付けて保存する。測定回数に応じて `-X1`, `-X2`, `-X3`… と数字を変える。例 `123456K-X1`
- **複数の条件**があるときは、左から順に付ける。例 回転単品クローズ `123456KRC`／2軸対向（固定）1軸目 `123456KMF`
- 運用: ① K32 使用欄は青枠内（駆動装置・アンクランプの セミクロ〜対向（移動））② オレンジ（黄）枠内は、完組状態での慣らし有無の識別 ③ K33 へ分割依頼する場合は、本体に慣らし完了の表記をお願いする（慣らし未完了の場合の表記は不要）④ 上に当てはまらない場合は K33 澤田まで問い合わせる

## 読み取りで自信のない所（写真を見て確かめる）
- 正規モータ・アンクランプの傾斜単品・回転単品が、写真では「TT」「RR」と2文字に見える。表の決まり（セミクロ=なし、傾斜単品=T）から読むと「T」「R」のはず。**未確認**（アプリは T／R で作る。違えば1か所で直せる形にする）。
- 駆動装置・クランプの行の、完組の4列（TY〜DRY）は斜線で消されて見える（該当なし）。アプリは禁止せず、選べる形にしておく（推測で禁止しない）。
