# 測定条件は同じ型式でも最大3種類ある（2026-11-25 利用者の回答）

連続測定（フルクロ→セミクロ）の設計書（設計/フルクロ→セミクロ連続測定_設計.md）の確認4点に、利用者が答えた内容。

## 利用者の言葉をそのまま整理したこと
1. **測定条件はフルクロとセミクロで違う。** 同じ型式でも最大3種類ある。
   - セミクロ・**モーター**: 歯車の歯数ぶんの等分。歯1枚を10等分する。
   - セミクロ・**駆動装置**で測るとき: 歯1枚飛ばしでよい（ルール）。
   - **フルクロ（スケール付き）**: 使っているスケールで決まる。
2. セミクロの結果は、検査表（.BS）・Web には**出さない**。
3. 測り終わったあと、フルクロへ**戻すときと戻さないときがある**（選べるようにする）。
4. RTV-231 の再現性: **7回繰り返し・4等分**。

## 決めたこと（解釈に迷った所は仮決め・一行で伝える）
- 測定条件の登録に「測定の種類」（セミ・モーター／セミ・駆動装置／フル・スケール付き）を持たせ、同じ型式で3つまで登録できるようにする。引く鍵は 型式＋クローズ＋測定の種類。種類が空の既存の登録は「今までどおり」（変えない）。
- 「歯1枚飛ばし」は仮に「1歯おきに測る＝測る角度の刻みが歯2枚分」と読む（**未確認**。違えば直す）。
- セミの結果は .BS・Web に出さない（セミ測定のセーブでは .BS を書かない）。同じ機番で上書きしないよう、ファイル名に種類を付ける。
- 戻す／戻さないは、連続測定の最後に選ぶ（既定は「戻す」。戻すときは機械の控えから戻す値を書く案内）。
- RTV-231 の再現性は 7回・4等分（ブロック数4・回数7）として登録する。

## 先にやること
測定条件の登録が3種類を持てるようにする（登録・読み込み・はじめてモードの「測り方」）。連続測定の帯はそのあと。
