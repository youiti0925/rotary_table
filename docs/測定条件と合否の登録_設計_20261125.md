## 0. 結論（先に）

1. **表の形は今のままでよい。** 専用の Excel（`マスタ/測定条件_種類別.xlsx`）の「回転」「傾斜」シートに、
   **1行 = 型式 × 測定の種類（× スケール名）** で、測り方・再現性・合否の規格を横に並べる。回転か傾斜かはシートで分ける。
2. **傾斜の合否は、いま決められない。** 傾斜で何を合否にするのか（項目）と、その規格の形を、利用者に聞く必要がある（§3 の4問）。
   答えが出るまで、傾斜シートの MINA・MINB・MAXA・MAXB は**登録画面とひな形から隠す**（書いても判定に使わない欄を見せない）。
   傾きH・傾きW だけは今のまま使う。
3. **引き継ぎは「欄ごと」ではなく「かたまりごと」にする。** いまは空の欄だけ合否判定.csv の値で埋めるので、
   1行の中に「この行の値」と「前の表の値」が混ざる。バックラッシの4つの値で1かたまり、傾きの2つで1かたまりにして、
   かたまり単位で「この行」か「前の表」かを決め、画面にどちらの値かを出す。
4. **Excel を人が書いても壊れにくくする直しは7つ**（§5）。いちばん大事なのは
   「数字として読めない字が入っていたら、黙って空欄扱いにしない」こと。いまは黙って空欄になり、前の表の値で合否が出てしまう。
5. ファイル名の記号（K・I・G・T・R・C など）は**この表には持たない**。
   モーター（正規／仮／駆動装置）とクランプは測るたびに違うので、社内の表（`serial_suffix.py`）から測るときに決める（今のまま）。

## 2. 1行に何を持つか【案】

**1行 = 型式 × 測定の種類 ×（フルクロのときだけ）スケール名。回転と傾斜はシートで分ける。** いまの形を変えない。

- 2軸の製品（回転と傾斜）は、同じ型式を「回転」「傾斜」の両方のシートに書く。それぞれ最大3種類。
- 同じ行に、測り方・再現性・合否の規格を全部置く。「この型式をこの種類で測るときのこと」が1行で読めるほうが、人が Excel で書きやすい。
  規格だけ別シートに分ける案は取らない（型式と種類を2か所に書くことになり、片方だけ直す間違いが起きる）。
- 型式の欄には、利用者が画面に打つ書き方をそのまま書く（クローズ記号つきなら `RB-250Ri`）。引き方は §4-4。
- ファイル名の記号は持たない（§0 の5）。

### 2-1. 合否の欄（回転シート）
| 欄 | 意味 | 空のとき |
|---|---|---|
| MINA・MINB・MAXA・MAXB | 総合バックラッシの下限＝MINA×温度＋MINB、上限＝MAXA×温度＋MAXB。**4つで1かたまり** | 4つとも空 → 前の表（合否判定.csv）のかたまり。1つでも書いてあれば、この行の4つを使う（A の空は 0。MAXB が空なら「上限が書いてありません」と出して判定しない） |
| 傾きH・傾きW | 傾きの規格（秒）。**2つで1かたまり** | 2つとも空 → 前の表。片方だけ書いてあれば、書いていないほうは「判定しない」 |

- 見出しの名前（MINA など）は変えない。合否判定.csv と同じ名前で、現場が見慣れている。意味は見出しのセルのコメントと「説明」シートに日本語で書く。
- 割出精度そのもの・再現性の規格の欄は、**利用者の答え（§3 の問1）を聞いてから足す**。足すなら
  「精度の上限」「再現性の上限」（どちらも秒。空なら判定しない）の2欄を、回転・傾斜の両方に同じ名前で足す。

### 2-2. 合否の欄（傾斜シート）
- いま確かに使えるのは **傾きH・傾きW だけ**。これは残す。
- MINA〜MAXB は、答えが出るまで登録画面とひな形に出さない（§1-3 の C）。すでに欄がある表はそのまま読めるが、
  値が書いてあれば「傾斜のバックラッシの規格は、まだ判定に使っていません」と画面に出す。
- 答えのあとの形（どちらかになる）:
  - 傾斜のバックラッシも温度で変わる → 回転と同じ4欄を、そのまま判定に使う。
  - 温度で変わらない → 「バックラッシ下限」「バックラッシ上限」（秒）の2欄にする。MINA〜MAXB は傾斜から消す。
  - 傾斜はバックラッシを合否にしない → 欄を消す。

## 3. 利用者に確かめること（4問）

傾斜の規格は「回転と全く違う」と聞いているが、**何が違うのか（項目か、値か、式の形か）はまだ聞けていない。** ここが決まらないと欄を決められない。

| 問 | 聞くこと | 答えで変わること |
|---|---|---|
| 1 | 傾斜で合格・不合格を出す項目はどれか。割出精度（誤差の幅）／傾き／バックラッシ／再現性／任意誤差。いまアプリが傾斜で赤くするのは、傾きと、単一5秒・隣接10秒だけ | 傾斜シートに足す欄。回転にも同じ欄（精度の上限・再現性の上限）が要るか |
| 2 | 傾斜のバックラッシの規格は、回転のように温度で変わるか、決まった上限・下限か、そもそも見ないか | §2-2 の3つの形のどれか |
| 3 | 規格は3種類（セミ・モーター／セミ・駆動装置／フル・スケール付き）で違うか。いまの回転の合否の表（合否判定.csv）の値は、3種類のどれに使ってよいか | 空欄のとき前の表から引き継いでよい種類。フルクロに引き継いではいけないなら、フルクロは「未登録」と出す |
| 4 | 傾斜の規格が書いてある表（紙でも Excel でも）はあるか。あれば写真か置き場所 | あれば全型式をまとめて入れる。無ければ測るときに1型式ずつ登録 |

問3の答えが来るまでの仮の動き: 3種類とも前の表から引き継ぐ。ただし画面に「前の表（合否判定.csv）の値です」と必ず出す。

## 4. 引き継ぎの決まり【案】

「黙って別の値を使わない」を全部に通す。使った値がどこから来たかは、測定の画面の種類のボタンの下に1行で出す
（例「測り方: この種類の登録／バックラッシの規格: 前の表／傾きの規格: この種類の登録」）。

### 4-1. 測り方（刻み・範囲など）
| 場面 | 動き |
|---|---|
| 種類を選んでいて、その行がある | その行 |
| 種類を選んでいて、その行が**無い** | **止めて理由を出す**「（種類）の測り方が登録されていません」＋「登録する」ボタン。「種類が空」の行は使わない（§1-3 の D を直す） |
| 種類を選んでいない | 「種類が空」の行 → 無ければ今までの引き方（ユーザー登録 → 測定条件.csv）。今のまま |
| セミ・モーターで刻みが空、歯数がある | 360÷歯数÷10。今のまま |

### 4-2. 合否の規格
| 場面 | 動き |
|---|---|
| 回転・かたまりに値がある | この行のかたまり |
| 回転・かたまりが全部空 | 前の表（合否判定.csv）の同じ型式のかたまり。画面に「前の表の値」と出す |
| 回転・どちらにも無い | 判定しない。「規格が登録されていません」と出す（「合格」とは言わない） |
| 傾斜 | **どこからも引き継がない**（回転の値・合否判定.csv・ほかの種類）。空なら「傾斜の規格が未登録」。今のまま |

### 4-3. 再現性・測る予定
- 再現性（ブロック数・回数・開始・終了）は、種類の間でも回転と傾斜の間でも引き継がない。空なら、その種類の再現性は作らない。今のまま。
- 測る予定は、傾斜の行が無ければ回転と同じ。今のまま。

### 4-4. 型式の比べ方（1つに揃える。§1-3 の E）
比べる前に両方を同じ形にする: 全角→半角、小文字→大文字、前後と途中の空白を取る、長音・全角のハイフン（ー － ‐ ―）→ `-`。
引く順: ①そのまま → ②カンマを詰めた形 → ③カンマの前だけ → ④末尾の英字（クローズ記号）を外した形。
④で当たったときは、画面に「RB-250 の登録を使っています」と出す。合否判定.csv も種類別の表も同じ関数で引く。

### 4-5. はじめに表を作るとき（今までの登録の写し）
今のまま: 今までの登録を「種類が空」の行として写す。合否判定.csv の値も回転の行に写す。傾斜には写さない。
ある表は上書きしない。

## 5. Excel を人が直接書いても壊れにくい形【案】

| # | 直すこと | 関係する §1-3 |
|---|---|---|
| 1 | **数字の欄**: 全角の数字・前後の空白は読む。それ以外の字（`3,5`・`3秒` など）は「（シート）（型式）（種類）の（欄）が数字として読めません」と出し、**その行のそのかたまりは使わない**（前の表にも落とさない） | A |
| 2 | **式の入った欄**: 値が読めて式があるときはそのまま読む。値が読めず式だけあるときは「Excel で一度開いて保存してください」と出し、1 と同じ扱い。アプリの保存では式を消さない | F |
| 3 | **見出し**: 知っている名前に無い見出し・足りない見出しを、表を読んだときに出す（空白の違いだけなら読む）。人が足した列（社内メモなど）は「知らない列: ○○（使いません）」と1回だけ出し、保存しても残す | G |
| 4 | **選ぶ欄は一覧から選ばせる**: 測定の種類・回転/傾斜・フルで測る・セミで測る・セミの種類に、Excel の「一覧から選ぶ」（入力規則）を付ける。手で打った表記ゆれ（中点・空白）は今までどおり読む | — |
| 5 | **アプリの保存は、ある行をその場で書き換える**: 同じ 型式＋種類＋スケール名 の行があれば、画面にある欄のセルだけ書き換える。無ければ末尾に足す。行を消すのは、画面でその種類を空にして保存したときだけで、消す前に「（種類）の行を消します」と出す | H |
| 6 | **控えは日付つきで10個まで**: `マスタ/控え/測定条件_種類別_20261125_1830.xlsx`。Excel で開いたままで保存できないときは「Excel で開いています。閉じてからもう一度」と出す（今は英語のエラー文がそのまま出る） | I |
| 7 | **読んだ結果を1か所で見られる**: 登録画面の下に「この表の気になる所 N 件」（重なった行・読めない数字・知らない見出し）を出す。測定の画面では、いま使う型式に関係するものだけ出す | A・G |

- 同じ 型式＋種類＋スケール名 が2行あるとき: 今のまま「上の行を使う」＋知らせる。
- 見出しは1行目だけ。2行目に説明の行は置かない（読み方が複雑になる）。説明は見出しのコメントと「説明」シート。
- 表の置き場所は今のまま PC ごと（設定で共有フォルダを指せる）。複数の PC で同じ表を使うかは、表の中身が固まってから決める。
