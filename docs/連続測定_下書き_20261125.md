## 利用者が言ったこと（そのまま整理）
- 製品によって、フルクロで分割と再現性を測り、そのあとセミクロにして分割だけ測る、がある。RTV-231 はたまたま両方ある。
- 「フルクロとセミクロをやる」という予定は、型式で登録しておけば、受注伝票番号 → 型式 → 予定、と出る。
- 制御装置を選んだあとは、(a) フルクロが終わったら自動でセミクロへ行く、または (b) フル／セミのどちらを先にするか選べる。
- 1台目がセミクロで終わったら、2台目は載せ替えて、セミクロから測ってよい。その場合、パラメータの変更とプログラムはそのままでよいので飛ばす。フルクロにするときだけ変更する。

## 作り方の案
1. **予定の登録**: 種類別Excel（マスタ/測定条件_種類別.xlsx）に3つめのシート「測る予定」を足す。列: 型式 / フルで測る（分割・再現性・両方・しない）/ セミで測る（同）/ セミの種類（モーター・駆動装置）。空欄は「予定なし」（今までどおり1回測るだけ）。
2. **予定が出る**: 伝票番号 → 製品 → 型式 → 「測る予定: フル（分割＋再現性）→ セミ（分割だけ）」を1行で出す。
3. **先にどちらか**: 制御装置を選んでつないだあと、機械の今の状態を読む（フルかセミかは、1815 の #1（1＝フル）の読み値で分かる）。今の状態のまま測れる方を既定にして、「フル先／セミ先」を選べる。
4. **1つ目が終わったら**: 自動で次の工程の案内へ。切り替えるときだけ「書く → 電源の入れ直し・原点の決め直し → プログラムを送る」。測る・保存は今までどおり。
5. **2台目以降（載せ替え）**: 機械の今の状態から始める。いまの状態と測る種類が同じなら、書く・送るを飛ばし、画面に1行「このまま測れます」と出す。違うときだけ切り替えの案内。
6. **取り違え防止**: セミの結果は検査表（.BS）・Web に出さない。機番のファイルは種類を付けて別名で保存し、上書きしない。セーブ前に「いま入っているのはフル／セミ」を画面に出す。
